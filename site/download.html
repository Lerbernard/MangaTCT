MangaTCT for Windows

Windows 10 or 11, 64-bit. One installer, no administrator password, and it updates itself from then on.

All releases

Windows will warn you the first time. The installer is not signed yet - a code-signing certificate is the next thing on the list - so SmartScreen says "Windows protected your PC". Click More info, then Run anyway.

What happens when you run it

  1. Install, about a minute. It goes into your own user folder, so there is no administrator prompt. Nothing is added to your system settings and nothing runs in the background.
  2. The first start downloads the text models, about 200 MB. They come from the people who published them, not from us - we are not allowed to redistribute them, which is also why they are not in the installer. It says which one it is fetching while it does it.
  3. Then MangaTCT opens in its own window. Under the hood it is a local program serving a page to that window at 127.0.0.1 - nothing leaves your machine. Point it at a folder of pages and press Find text. (Prefer a browser tab? Open in browser is on the little launcher window.)
  4. Add your API key when you want to translate. Finding text, cleaning and typesetting cost nothing and need no key. Reading and translating call Claude, Gemini or OpenRouter - your key, or coins bought here. What things cost.

Updates

It updates itself

Every time you start MangaTCT it checks for a new version, and a new version is a few megabytes, not another 250. You never reinstall.

An update that arrives while you are working is used the next time you start - a chapter open on screen is never swapped out from under you.

If something goes wrong

The previous version stays on your disk, and MangaTCT falls back to it by itself if a new one cannot start.

In the app: File › Report a problem gathers your version, your machine and the last lines of the log, with anything key-shaped taken out, ready to paste.

Where things go

%LOCALAPPDATA%\MangaTCTthe app, its Python and the models
~\.mangatlyour fonts, settings and keys - untouched by updates and by uninstalling
Documents\MangaTCTexported pages, unless you pick a folder

Not on Windows?

The app is Python and runs on macOS and Linux, but there is no installer for them yet and the beta is not tested there. If you are comfortable with a terminal, download the source of the current release (every version's is on the releases page) - unzip it, pip install -r requirements.txt, and python -m mangatl.editor.
