# The two specialist detectors (Settings -> Text detector). Optional in the
# sense that nothing runs unless the two checkpoints are downloaded AND the
# switch is on -- but not optional once they are, so they are named here
# rather than left to fail at the first page:
#
#   einops     the manga-text model rearranges its feature map for the
#              self-attention block  (detect/_dbnet/DBNet_resnet34.py)
#   pyclipper  DB shrinks its polygons when it trains and they have to be
#              pushed back out  (detect/onomatopoeia.py)
#   shapely    ...and the offset is computed off the polygon's own area
#              over its perimeter
#   ultralytics  the Manga109 segmenter is a YOLO26 checkpoint and there is
#              no reading one without it  (detect/mangaseg.py)
#
# `dbtext.why_not`, `onomatopoeia.why_not` and `mangaseg.why_not` say which
# is missing, and `Project.two_specialists` / `Project.manga_segmenter`
# refuse to switch their route on until none of them is -- a machine with the
# weights and not the wheels detects the way it always did instead of
# crashing mid-run.
einops>=0.7
pyclipper>=1.3
shapely>=2.0
ultralytics>=8.2
